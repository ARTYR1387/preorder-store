# Публикация в GitHub

В этой сессии нет авторизованного GitHub CLI или подключённого GitHub-коннектора. Репозиторий не создавался и файлы не публиковались. Владелец должен передать URL целевого репозитория и предоставить авторизованный способ записи; затем локальный проект можно отправить в него.

## Создать новый репозиторий

Создайте пустой приватный репозиторий в GitHub, не добавляя README, лицензию или `.gitignore`, поскольку эти файлы уже входят в проект. Затем выполните из корня проекта команды, подставив свой URL:

```bash
git init
git add .
git commit -m "Create PreOrder Store coursework project"
git branch -M main
git remote add origin <URL-репозитория>
git push -u origin main
```

Публикуйте только в репозиторий, который принадлежит вам или на запись в который вы явно имеете право. Файл базы, секреты и локальные пользовательские данные не добавляйте.

## Получить проект на другом компьютере

```bash
git clone <URL-репозитория>
cd <папка-проекта>
dotnet restore PreOrderStore.sln
dotnet build PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

Если репозиторий уже клонирован:

```bash
git pull
```

Перед передачей изменений сверьте требования кафедры и замените пустые поля на титульной странице курсовой.
