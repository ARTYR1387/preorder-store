# Сценарии тестирования PreOrder Store

Текущая сборка: .NET 10 / Avalonia 12. Каталог подключён к DummyJSON, товары сохраняются в SQLite. Демо-оплата не вызывает настоящий платежный сервис и не списывает деньги.

## Автоматизированные проверки

| ID | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| A01 | `dotnet build PreOrderStore.sln` | Решение собирается без ошибок | Пройдено |
| A02 | `dotnet test PreOrderStore.sln` | Все текущие xUnit тесты успешны | Пройдено: 12/12 |
| A03 | Создать заказ положительного количества | Сохраняются количество и цена на момент заказа | Автоматизировано |
| A04 | Нулевое/отрицательное количество | Операция отклонена | Автоматизировано |
| A05 | Количество больше остатка | Операция отклонена | Автоматизировано |
| A06 | Повторная активная покупка сверх остатка | Повторное превышение ограничивается | Автоматизировано |
| A07 | Отменить ожидающую покупку | Статус меняется, доступность пересчитывается | Автоматизировано |
| A08 | Повторная отмена | Сервис отказывает | Автоматизировано |
| A09 | Синхронизировать один внешний ID дважды | Дубликат продукта не появляется | Автоматизировано |
| A10 | Обновить цену товара после оформления | Цена-снимок в существующей записи не меняется | Автоматизировано |
| A11 | Купить из пользовательской корзины | Создаётся покупка пользователя, корзина очищена | Автоматизировано |
| A12 | Прочитать или отменить чужую покупку | Чужая история недоступна | Автоматизировано |
| A13 | PBKDF2 registration/sign-in | Пароль не сохраняется открытым текстом; email нечувствителен к регистру | Автоматизировано |
| A14 | Ненадёжный пароль/дубликат email | Регистрация отклоняется | Автоматизировано |

Актуальные автоматические тесты покрывают сервисную логику. Полный интерфейсный поток с живым API и кликанием платежного экрана не входит в эти 12 тестов; проверьте его вручную по сценариям ниже.

## Ручная проверка desktop UI

| ID | Проверка | Действия | Ожидаемый результат |
|---|---|---|---|
| M01 | Гостевой старт | Запустить приложение без ввода логина | Открывается каталог; регистрация не блокирует просмотр |
| M02 | Каталог API | Иметь сеть, дождаться фоновой синхронизации | Счётчик каталога обновляется; карточки отображаются из SQLite |
| M03 | Фильтрация | Ввести поиск, выбрать категорию и статус, изменить сортировку | Список реагирует без перезапуска |
| M04 | Светлая/тёмная тема | Нажать переключатель темы | Цвета фона, поверхностей, текста и кнопок меняются; текст читаем |
| M05 | Гостевая корзина | Добавить и удалить товар без входа | Счётчик и сумма меняются; позиции доступны при открытом приложении |
| M06 | Переход к покупке | Из гостевой корзины нажать «Перейти к покупке» | Появляется форма входа/регистрации; покупки ещё нет |
| M07 | Пропуск регистрации | Нажать «Пропустить регистрацию · продолжить гостем» | Форма закрывается; каталог и корзина доступны; заказ не создан |
| M08 | Регистрация при покупке | Создать аккаунт из формы, открывшейся на checkout | Сессия открывается; гостевые позиции переносятся в аккаунтную корзину |
| M09 | Демо-оплата | Нажать оформить и проверить экран до подтверждения | Ясно обозначено отсутствие списания; данных карты не просят |
| M10 | Подтвердить оплату | Нажать «Подтвердить демо-оплату» | Покупка сохраняется в SQLite, корзина очищается, история отображает статус демо-оплаты |
| M11 | Offline cache | После успешной загрузки отключить интернет и перезапустить | Ранее сохранённые товары доступны из SQLite; UI сообщает о сетевой недоступности |
| M12 | Повторное API обновление | Включить интернет и нажать «Обновить товары» | API-товары вставляются или обновляются без дублей |
| M13 | Изоляция аккаунтов | Создать покупку, выйти, войти другим локальным аккаунтом | Другой пользователь не видит первую историю |
| M14 | Миграция БД | Запустить версию поверх существующей SQLite | EF применяет недостающие миграции без ручного удаления файла базы |

Команды из корня проекта:

```bash
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

Результат компиляции не подменяет проверку пользовательского интерфейса на целевой Windows-машине. Товары и числа DummyJSON — примерные данные; успешная демо-оплата не подтверждает настоящий платёж или продажу.
