# Сценарии тестирования PreOrder Store

Текущая сборка: .NET 10 / Avalonia 12. Каталог синхронизируется с внешним источником и кэшируется в SQLite. Платёжный сервис пока не подключён: интерфейс не создаёт оплаченный заказ.

## Автоматизированные проверки

| ID | Сценарий | Ожидаемый результат | Статус |
|---|---|---|---|
| A01 | `dotnet build PreOrderStore.sln` | Решение собирается без ошибок | Пройдено |
| A02 | `dotnet test PreOrderStore.sln` | Все текущие xUnit тесты успешны | Пройдено: 21/21 |
| A03 | Создать заказ положительного количества | Сохраняются количество и цена на момент заказа | Автоматизировано |
| A04 | Нулевое/отрицательное количество | Операция отклонена | Автоматизировано |
| A05 | Количество больше остатка | Операция отклонена | Автоматизировано |
| A06 | Повторная активная покупка сверх остатка | Повторное превышение ограничивается | Автоматизировано |
| A07 | Отменить ожидающую покупку | Статус меняется, доступность пересчитывается | Автоматизировано |
| A08 | Повторная отмена | Сервис отказывает | Автоматизировано |
| A09 | Синхронизировать один внешний ID дважды | Дубликат продукта не появляется | Автоматизировано |
| A10 | Обновить цену товара после оформления | Цена-снимок в существующей записи не меняется | Автоматизировано |
| A11 | Сервис создаёт ожидающий оплаты заказ | Сохраняется снимок цены; заказ не отмечен оплаченным, корзина очищена внутри сервисной операции | Автоматизировано |
| A12 | Прочитать или отменить чужую покупку | Чужая история недоступна | Автоматизировано |
| A13 | PBKDF2 registration/sign-in | Пароль не сохраняется открытым текстом; email нечувствителен к регистру | Автоматизировано |
| A14 | Ненадёжный пароль/дубликат email | Регистрация отклоняется | Автоматизировано |
| A15 | Избранное двух покупателей | Пары customer/product уникальны и изолированы | Автоматизировано |
| A16 | Создать и удалить локальный товар | Позиция появляется в SQLite и удаляется до использования | Автоматизировано |
| A17 | Удаление API-позиции или позиции из корзины/истории | Сервис блокирует удаление | Автоматизировано |
| A18 | Регистрация первого аккаунта | Аккаунт получает роль администратора | Автоматизировано |
| A19 | Разбор подробностей API товара | Корректно извлекаются HTTPS-фото, рейтинг и валидные отзывы | Автоматизировано |
| A20 | Идентификатор локального товара в API-провайдере | Сетевой запрос не выполняется; возвращается отсутствие API-подробностей | Автоматизировано |
| A21 | Русское описание известного API-ID | Провайдер использует встроенный русский перевод вместо английского текста API | Автоматизировано |
| A22 | Полное удаление позиции | Строка удаляется независимо от количества, другие аккаунты не затрагиваются | Автоматизировано |
| A23 | Очистка корзины | Удаляются только позиции указанного аккаунта | Автоматизировано |

Актуальные автоматические тесты покрывают сервисную логику, парсинг источника, локальный перевод и операции корзины. Полный интерфейсный поток с живым источником и кликами по экрану оформления не входит в эти 21 тест; проверьте его вручную по сценариям ниже.

## Ручная проверка desktop UI

| ID | Проверка | Действия | Ожидаемый результат |
|---|---|---|---|
| M01 | Гостевой старт | Запустить приложение без ввода логина | Открывается каталог; регистрация не блокирует просмотр |
| M02 | Каталог API и фото | Иметь сеть, дождаться фоновой синхронизации | Карточки из SQLite видны с фотографиями; изображения не блокируют окно |
| M03 | Фильтрация | Ввести поиск, выбрать категорию и статус, изменить сортировку | Список реагирует без перезапуска |
| M04 | Светлая/тёмная тема | Нажать переключатель темы | Цвета фона, поверхностей, текста и кнопок меняются; текст читаем |
| M05 | Гостевая корзина | Добавить товар, нажать минус в карточке, открыть корзину, удалить строку и очистить всё | Счётчик и сумма меняются; кнопки доступны без входа; корзина полностью очищается по команде |
| M06 | Переход к покупке | Из гостевой корзины нажать «Перейти к покупке» | Появляется форма входа/регистрации; покупки ещё нет |
| M07 | Пропуск регистрации | Нажать «Пропустить регистрацию · продолжить гостем» | Форма закрывается; каталог и корзина доступны; заказ не создан |
| M08 | Регистрация при покупке | Создать аккаунт из формы, открывшейся на checkout | Сессия открывается; гостевые позиции переносятся в аккаунтную корзину |
| M09 | Экран оформления | После входа нажать «Перейти к покупке» | Видно, что оплата ещё не подключена; реквизиты карты не запрашиваются |
| M10 | Сохранение корзины | На экране оплаты нажать «Назад в корзину» | Заказ не создаётся и не помечается оплаченным; состав и сумма корзины сохранены |
| M11 | Offline cache | После успешной загрузки отключить интернет и перезапустить | Ранее сохранённые товары доступны из SQLite; UI сообщает о сетевой недоступности |
| M12 | Повторное API обновление | Включить интернет и нажать «Обновить товары» | API-товары вставляются или обновляются без дублей |
| M13 | Изоляция аккаунтов | Создать покупку, выйти, войти другим локальным аккаунтом | Другой пользователь не видит первую историю |
| M14 | Миграция БД | Запустить версию поверх существующей SQLite с аккаунтом | EF применяет миграции, сохраняет данные и назначает администратора самому раннему аккаунту |
| M15 | Страница товара | Нажать на фото или «Подробнее о товаре» | Открывается полноценная страница; появляется фото, галерея, описание, рейтинг, отзывы API и действия; «Назад» возвращает в прежнюю секцию |
| M16 | Избранное гостя | Нажать сердце на карточке и открыть «Избранное» | Иконка меняет состояние, позиция отображается в избранном; повторный щелчок убирает её |
| M17 | Избранное аккаунта | Войти, поставить/снять сердце и перезапустить приложение | Избранное хранится в SQLite отдельно для аккаунта |
| M18 | Анимации корзины | Добавить товар из каталога, затем увеличить, уменьшить и убрать его | Мини-карточка летит к корзине; строка мягко появляется/уходит; счётчик акцентируется, цена пересчитана |
| M19 | Добавить локальный товар | Ввести поля в разделе «Добавить товар» и сохранить | Товар виден в каталоге и остаётся там после обновления DummyJSON |
| M20 | Удалить локальный товар | Удалить созданную позицию, не использованную в корзине или покупке | Товар удалён; действие над API-товаром недоступно |
| M21 | Защита использованной позиции | Поместить локальную позицию в корзину или покупку, затем запросить удаление | Сервис отклоняет удаление и объясняет причину |
| M22 | Большой каталог | Открыть каталог с большим числом товаров, затем нажать «Показать ещё» | Сначала отображаются 8 карточек; изображения загружаются не более чем по 2 одновременно; новые карточки добавляются порциями без заметного зависания |
| M23 | Ограничение управления | Войти первым аккаунтом, затем войти покупателем | Администратор видит инструменты добавления/удаления локальных товаров; покупатель их не видит |
| M24 | Анимация и переключение фотографий | Открыть товар, дождаться фото и выбрать другую миниатюру | Фото плавно появляется; выбранная миниатюра меняет большое изображение |
| M25 | Офлайн-отзывы | Отключить сеть и открыть API-товар | Страница и описание доступны из кэша; интерфейс сообщает, что отзывы/галерея API временно недоступны |
| M26 | Нажатие на карточку | Нажать на свободную область карточки, не на избранное или корзину | Открывается полная страница выбранного товара; отдельная маленькая ссылка не обязательна |
| M27 | Кнопка удаления | Войти первым аккаунтом и открыть локальный товар | Рядом с добавлением в корзину видна подписанная кнопка «Удалить»; у покупателя и API-товара её нет |
| M28 | Русское описание | Открыть товар из текущего DummyJSON каталога | Текст описания и название категории на русском и доступен из локального кэша после синхронизации |

Команды из корня проекта:

```bash
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

Результат компиляции не подменяет проверку пользовательского интерфейса на целевой Windows-машине. Цены и остатки внешнего каталога приведены для ориентира; платёжная интеграция ещё не реализована.
