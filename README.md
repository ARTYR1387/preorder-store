# PreOrder Store

Учебное Avalonia desktop-приложение магазина предзаказов на C#/.NET 10. Это offline-демонстрация с локальной регистрацией, персональной корзиной, историей и условными новинками в рублях. Товары, иллюстрации, цены, количество и статус — демонстрационные концепты; дата выхода в каталоге указана как уточняемая. **Реальной продажи, резервирования у поставщика и оплаты нет.**

## Запуск

Нужен .NET 10 SDK. Из корня клонированного репозитория:

```bash
dotnet restore PreOrderStore.sln
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

При первом запуске создаётся или обновляется пользовательская SQLite-база, затем открывается локальная регистрация и вход. Новые аккаунты/пароли, корзины и заказы сохраняются только в базе этого компьютера. Пароль маскируется в UI и хранится как salted PBKDF2 hash; email используется как локальный логин. Если вы обновляете уже установленную версию, новая EF migration добавит необходимые таблицы и поля; вручную удалять базу не нужно.

## Возможности

- локальная регистрация и вход;
- демонстрационный upcoming-каталог с авторскими SVG-концептами;
- поиск, фильтр по категории/доступности и сортировка;
- пользовательская SQLite-корзина с управлением количеством;
- оформление локальных предзаказов с фиксацией цены, валидацией демонстрационного остатка и транзакционной очисткой корзины;
- история и отмена только собственных ожидающих предзаказов;
- SVG-иконки вместо эмодзи и короткие переходы состояний UI.

## Архитектура

`PreOrderStore/Domain` содержит модели; `Data` — SQLite context и миграции; `Infrastructure` — локальный demo-feed и каталог SVG; `Services` — PBKDF2-аутентификация, синхронизация демо-витрины и checkout; `ViewModels` — MVVM-состояние и команды; `Views` — Avalonia XAML. `PreOrderStore.Tests` содержит интеграционные проверки на SQLite in-memory.

## Тесты

`dotnet test PreOrderStore.sln` — 11 автоматических случаев для регистрации/входа, изоляции пользователей, корзины/checkout, цены-снимка, проверки количества, отмены и синхронизации демонстрационных данных. UI следует отдельно запустить и проверить на целевом компьютере.

## Границы демо

Нет подтверждения электронной почты и восстановления пароля, серверного API, синхронизации между устройствами, платёжной системы, доставки или real-time поставщика. Даже сообщение приложения «предзаказ оформлен» означает только локальную запись в SQLite и не создаёт обязательств у продавца.
