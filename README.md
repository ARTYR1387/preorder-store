# PreOrder Store

Настольное приложение каталога на C#, .NET 10, Avalonia UI 12, EF Core и SQLite. Каталог доступен без аккаунта: гость может искать и фильтровать товары, открывать подробную страницу, добавлять позиции в избранное и собирать временную корзину. Первая попытка оформления предлагает вход или регистрацию; гостевые корзина и избранное затем переносятся в аккаунт.

Каталог синхронизируется с публичным [DummyJSON Products API](https://dummyjson.com/docs/products) и сохраняется локально. Это источник примерных данных, а не магазин-продавец; цена отображается с постоянным множителем `90`, а наличие требует подтверждения. Эти технические подписи не показываются в интерфейсе.

В списке показывается по 8 карточек. Их изображения загружаются в фоне с ограничением до двух одновременных загрузок и декодирований, чтобы уменьшить паузу при нажатии «Показать ещё». Фотография постепенно проявляется; при добавлении товара небольшая карточка летит к счётчику корзины. В каталоге кнопка меняется с плюса на минус, так что количество можно уменьшить без перехода в корзину. В корзине доступны увеличение, уменьшение, полное удаление отдельной строки и очистка корзины. Нажатие на свободное место карточки открывает страницу товара; избранное и cart controls работают отдельно от перехода.

На странице товара показаны галерея фотографий, описание, цена, рейтинг и примеры отзывов. Пометка рядом с отзывами сообщает, что они не являются реальными отзывами покупателей магазина. Описания 194 текущих позиций переведены на русский и включены в приложение для офлайн-использования; для неизвестных новых ID используется исходный текст источника.

Управление ассортиментом доступно только локальному администратору. Первый зарегистрированный аккаунт получает роль администратора; последующие — покупателей. Администратор может создавать локальные позиции и удалять только свои неиспользованные товары.

## Оплата

Платёжный сервис пока не подключён. Кнопка оформления открывает информационный экран, корзина сохраняется, заказ не создаётся и товар не помечается оплаченным. Поля банковской карты не запрашиваются. Реальную интеграцию платежей планируется реализовать отдельным этапом.

## Запуск

Нужен .NET 10 SDK. Из корня репозитория:

```bash
dotnet restore PreOrderStore.sln
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

При старте EF Core применяет миграции к пользовательской SQLite-базе. Сначала отображается локальный кэш; синхронизация каталога выполняется в фоне. Кнопка «Обновить товары» повторяет синхронизацию.

Аккаунты, аккаунтные корзины, избранное и история хранятся на этом устройстве. Пароли сохраняются как salted PBKDF2 hash; это не серверная учётная запись.

## Архитектура и проверки

`Domain` содержит сущности товара, пользователя, корзины, избранного и покупки. `Data` — контекст SQLite и EF Core migrations. `Infrastructure/DummyJsonProductProvider.cs` загружает каталог и сведения о товаре; `CatalogSyncService` обновляет локальный кэш. `StoreService` управляет избранным и корзиной, включая уменьшение количества и полное удаление строк. `Views` содержит Avalonia XAML, SVG-иконки и remote-image control; `ViewModels` управляет навигацией, темами и анимациями.

Последняя проверка: сборка `dotnet build PreOrderStore.sln` успешна, `dotnet test PreOrderStore.sln` — 21/21. Автоматические тесты включают очистку корзины и полное удаление позиции. Интерфейс дополнительно рекомендуется проверить на целевой Windows-машине.

Проект не включает production backend, облачную синхронизацию, подтверждение почты, проверенные коммерческие цены/остатки, платёжный шлюз или доставку. Для реального магазина потребуются серверная авторизация, контролируемый каталог и отдельная интеграция платежей.
