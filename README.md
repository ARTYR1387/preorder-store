# PreOrder Store

Настольное приложение каталога на C#, .NET 10, Avalonia UI 12, EF Core и SQLite. Каталог доступен без аккаунта: гость может искать и фильтровать товары, открывать подробную страницу, добавлять позиции в избранное и собирать временную корзину. Первая попытка оформления предлагает вход или регистрацию; гостевые корзина и избранное затем переносятся в аккаунт.

Каталог синхронизируется с публичным [DummyJSON Products API](https://dummyjson.com/docs/products) и сохраняется локально. Это источник примерных данных, а не магазин-продавец; цена отображается с постоянным множителем `90`, а наличие требует подтверждения. Эти технические подписи не показываются в интерфейсе.

В списке показывается по 8 карточек в виртуализируемых строках: UI создаёт элементы только для видимой области. Изображения загружаются в фоне максимум по две одновременно. Фотография постепенно проявляется; при добавлении товара небольшая карточка летит к счётчику корзины. В каталоге кнопка меняется с плюса на минус, так что количество можно уменьшить без перехода в корзину. В корзине доступны увеличение, уменьшение, полное удаление отдельной строки и очистка корзины. Нажатие на свободное место карточки открывает страницу товара; избранное и cart controls работают отдельно от перехода.

На странице товара показаны галерея фотографий, описание, цена, рейтинг и примеры отзывов. Пометка рядом с отзывами сообщает, что они не являются реальными отзывами покупателей магазина. Описания 194 текущих позиций переведены на русский и включены в приложение для офлайн-использования; для неизвестных новых ID используется исходный текст источника.

Управление ассортиментом доступно только локальному администратору. Первый зарегистрированный аккаунт получает роль администратора; последующие — покупателей. Администратор может создавать локальные позиции и удалять только свои неиспользованные товары.

## Оплата

После входа единственный способ оплаты — отдельное desktop-приложение [Demo Bank](https://github.com/ARTYR1387/demo-bank). PreOrder Store передаёт сумму и состав корзины через локальный named pipe с одноразовым токеном. Только после проверенного подтверждения создаются покупки и очищается корзина; отказ или закрытие окна оставляет корзину без изменений. Это учебная симуляция: банковские счета, карточные данные и денежные переводы не используются.

## Запуск

Нужен .NET 10 SDK. Из корня репозитория:

```bash
dotnet restore PreOrderStore.sln
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

При старте EF Core применяет миграции к пользовательской SQLite-базе. Сначала отображается локальный кэш; синхронизация каталога выполняется в фоне. Кнопка «Обновить товары» повторяет синхронизацию.

Для сценария оплаты склонируйте Demo Bank рядом с `preorder-store` и запускайте PreOrder Store. Если приложение расположено в другом месте, задайте переменную `PREORDER_DEMO_BANK_PROJECT`, указав путь к `DemoBank.csproj`.

Аккаунты, аккаунтные корзины, избранное и история хранятся на этом устройстве. Пароли сохраняются как salted PBKDF2 hash; это не серверная учётная запись.

## Получение обновлений

Репозиторий `ARTYR1387/preorder-store` приватный; для клонирования нужны права чтения.

```bash
git clone https://github.com/ARTYR1387/preorder-store.git
cd preorder-store
git pull origin main
```

В уже клонированной папке достаточно выполнить `git pull origin main`.

## Архитектура и проверки

`Domain` содержит сущности товара, пользователя, корзины, избранного и покупки. `Data` — контекст SQLite и EF Core migrations. `Infrastructure/DummyJsonProductProvider.cs` загружает каталог и сведения о товаре; `CatalogSyncService` обновляет локальный кэш. `StoreService` управляет избранным и корзиной. `DemoBankPaymentService` запускает второе приложение и проверяет одноразовое подтверждение перед записью покупки. Каталог отображает пары товаров через `ItemsControl` с `VirtualizingStackPanel` внутри `ScrollViewer`; авторизация закрывает магазин отдельной непрозрачной центральной страницей.

Последняя проверка: сборка `dotnet build PreOrderStore.sln` успешна, `dotnet test PreOrderStore.sln` — 21/21. Автоматические тесты включают очистку корзины и полное удаление позиции. Интерфейс дополнительно рекомендуется проверить на целевой Windows-машине.

Проект не включает production backend, облачную синхронизацию, подтверждение почты, проверенные коммерческие цены/остатки, настоящий платёжный шлюз или доставку. Demo Bank существует только для демонстрации межпроцессного платёжного сценария и не переводит деньги. Для реального магазина потребуются серверная авторизация и лицензированный платёжный провайдер.
