# PreOrder Store

Демонстрационное настольное приложение магазина предзаказов на C#, .NET 10 LTS и Avalonia 12. В каталоге отображаются товары из публичного DummyJSON Products API; предзаказы и локальные статусы сохраняются в SQLite.

> DummyJSON предоставляет демонстрационные, а не коммерческие данные. API не знает о предзаказах, не обещает даты поставки и не хранит отправленные изменения. Даты ожидаемого поступления в проекте генерируются локально для демонстрации, а статусы и заказы существуют только в локальной БД.

## Запуск

Нужен .NET 10 SDK. Из корня репозитория выполните:

```bash
dotnet restore PreOrderStore.sln
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

SQLite-файл создаётся в системной папке пользовательских данных `PreOrderStore/preorder-store.db`; миграции применяются при старте. Первый запуск обращается к `https://dummyjson.com/products?limit=0`. При недоступности интернета показываются ранее сохранённые товары. Сборка и тесты выполняются без запуска графического интерфейса.

Если репозиторий уже клонирован, получить опубликованные изменения можно командой:

```bash
git pull
```

Для нового клона замените URL на адрес репозитория владельца:

```bash
git clone <URL-репозитория>
```

## Возможности

Каталог поддерживает поиск по названию, фильтр категории, сортировку по дате ожидаемого поступления, названию и цене. Карточка товара показывает изображение, описание, цену, доступность и локальную демонстрационную дату поступления. Можно оформить предзаказ с положительным количеством, посмотреть историю и отменить ожидающий подтверждения заказ.

Цена товара копируется в заказ в момент оформления. Совокупное количество активных заказов проверяется по заявленному API-остатку товара. Повторная синхронизация обновляет карточку по уникальному внешнему ID и не удаляет исчезнувшие товары из истории. Транзакция применяется при оформлении.

## Архитектура

`PreOrderStore/Domain` содержит сущности и правила статусов. `Data` содержит EF Core SQLite контекст и миграции. `Infrastructure` изолирует JSON-API за `IProductProvider`. `Services` отвечает за синхронизацию каталога и сценарии заказов. `ViewModels` связывает операции со статусом интерфейса. `Views` содержит Avalonia XAML и асинхронную загрузку изображений. `PreOrderStore.Tests` проверяет сервисы с SQLite in-memory.

При запуске .NET Host/DI регистрирует SQLite DbContext, типизированный HttpClient, сервисы и ViewModel. База мигрируется до открытия окна.

## Проверки

Интеграционные тесты проверяют снимок цены и сумму заказа, положительное количество, превышение доступного остатка, отмену, освобождение зарезервированного количества, невозможность повторной отмены и идемпотентную синхронизацию без потери истории. Сценарий запроса DummyJSON дополнительно проверен на живом ответе во время разработки. Запускайте проверки командой `dotnet test PreOrderStore.sln`.

## Ограничения демонстрации

Авторизация и несколько пользователей не реализованы: список заказов относится к единственной локальной установке. Реальные платежи, подтверждение поставщиком и доставка отсутствуют. `Confirmed` и `Fulfilled` представлены как допустимые состояния модели, однако демонстрационный интерфейс не имитирует несуществующую интеграцию подтверждения.

Если API недоступен при первом запуске, каталог будет пустым до нажатия «Обновить каталог». Кэш удалённого изображения остаётся в памяти процесса. DummyJSON-остаток — только демонстрационный показатель, не гарантия резерва у продавца.
