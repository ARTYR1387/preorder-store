# PreOrder Store

Учебное desktop-приложение магазина на C#, .NET 10, Avalonia UI 12, EF Core и SQLite. Покупатель попадает в каталог как гость: можно искать товары, открывать карточки и собирать временную корзину без регистрации. При первой попытке покупки приложение предлагает войти или зарегистрироваться; кнопку можно пропустить и продолжить просмотр гостем. После входа корзина переносится в аккаунт.

Каталог загружается из публичного [DummyJSON Products API](https://dummyjson.com/docs/products), синхронизируется с SQLite и затем отображается из локальной базы. При недоступности сети приложение сохраняет и показывает ранее загруженный каталог. DummyJSON — источник placeholder-данных, не настоящий магазин. Публичный набор содержит товары, цены в нём не являются рублёвыми предложениями. Для учебного интерфейса цена API умножается на фиксированный коэффициент 90; это иллюстрация, не актуальный валютный курс.

Оплата является симуляцией: форма банковской карты не запрашивается, внешний платёжный сервис не вызывается, деньги не списываются. Подтверждение создаёт локальные записи покупок в SQLite. Наличие, цена, заказ и поставка не являются коммерческой офертой.

## Запуск

Нужен .NET 10 SDK. Из корня клонированного репозитория:

```bash
dotnet restore PreOrderStore.sln
dotnet build PreOrderStore.sln
dotnet test PreOrderStore.sln
dotnet run --project PreOrderStore/PreOrderStore.csproj
```

При запуске EF Core применяет миграции к локальной базе в `%LOCALAPPDATA%/PreOrderStore/preorder-store.db` (Windows) или в пользовательской папке приложения на другой ОС. Сначала на экране показан сохранённый кэш; загрузка DummyJSON запускается в фоне. При первом сетевом запуске список появится после успешного обновления. При ошибке сети каталог из SQLite остаётся доступен. Кнопка «Обновить товары» повторяет синхронизацию.

Локальные аккаунты, корзины и покупки хранятся только на этом устройстве. Пароль хранится в виде salted PBKDF2 hash; это не серверная учётная запись.

## Покупка и темы

1. Добавьте товар в корзину как гость. Гостевая корзина живёт в памяти, пока приложение открыто.
2. Нажмите «Перейти к покупке». Создайте профиль или войдите; гостевая корзина копируется в аккаунт.
3. Нажмите «Подтвердить демо-оплату». Приложение сохранит покупку и покажет её в истории, но не списывает средства.
4. Если не хотите создавать профиль, выберите «Пропустить регистрацию · продолжить гостем»; можно продолжить просмотр и вернуться к покупке позже.

Кнопка переключения в верхней части окна меняет светлую и тёмную темы. Выбор действует до закрытия приложения. В каталоге есть поиск, фильтр по категории и наличию, сортировка и карточка подробностей.

## Архитектура

`Domain` содержит сущности товара, покупателя, корзины и покупки. `Data` — контекст SQLite и EF migrations. `Infrastructure/DummyJsonProductProvider.cs` выполняет запрос к API; `CatalogSyncService` записывает/обновляет товары по внешнему ID. `StoreService` читает каталог из базы, проверяет остаток и транзакционно оформляет покупки. `AuthService` реализует локальную регистрацию и вход. `ViewModels` содержит состояния гостя, аккаунта, корзины, оплаты и фильтров. `Views` реализует Avalonia XAML, SVG, палитру тем и загрузчик сетевых thumbnail. Изображения карточек кэшируются в памяти во время сеанса, а адрес картинки хранится в записи товара.

## Проверки и ограничения

Текущий набор содержит 12 автоматических тестов бизнес-логики и SQLite. Последняя проверка: `dotnet build PreOrderStore.sln` успешна, 12/12 тестов пройдены. Дополнительно проверен запуск Avalonia под виртуальным дисплеем и ответ API с 194 товарами. GUI следует самостоятельно показать на целевой Windows-машине перед защитой.

Проект не включает production API, облачную синхронизацию, email verification, восстановление пароля, реальные цены и stock, платёжный шлюз, доставку или обязательства продавца. Для реального магазина нужны собственный backend, согласованный источник каталога/остатков, безопасный серверный вход и сертифицированная интеграция платежей.
